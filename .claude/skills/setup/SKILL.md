## いつ使うか
- ダウンロード・clone の直後。起動時の表示に `[要記入]` か `git がありません` が出たとき
- パックを後から足したいとき。「セットアップして」「初期設定して」と頼まれたとき

## 手順
1. `.git` が無ければ `git init` → `git add -A` → `git commit -m "chore: はじめる"`。あれば触らない。失敗したら `git config user.name "FDE Atlas 利用者"` と `git config user.email fde-atlas@localhost` をこのフォルダに設定し再実行、報告に1行書く
2. 1回のメッセージで4問を聞く。選択肢と既定値を添え、「未定」可。①業務名と完了条件 ②責任者 ③正本の置き場(3つまで。情報・場所・確かめ方) ④AGENTS.md 4節のほかに任せない操作。`packs/*/PACK.md` の `## /setup が聞くこと` の はい/いいえ の問いも1行ずつ添える(入っているパックは除く)。1節が記入済みなら4問と手順3を省く
3. 1節に業務名・完了条件・責任者・承認線の追加(無ければ `なし`)を書く。正本の置き場は未設定の印を消し、直下に `  - <情報>: <場所>(確かめ方: <…>)` を3行まで。答えの無い項目は `未定` とし、desk/TODAY.md のお知らせに `記入欄の未定: <項目名>` を1行足す。work/STATUS.md の1行目を `次の一手: 「壁打ちしたい」と頼み <業務名> の作業地図を作る` に、TODAY の `はじめに:` 行を `準備ができました: 次は <業務名> の作業地図づくりです。` に替える
4. はい のパックごとに、`packs/<名前>/` の PACK.md 以外を同じ相対パスへ python3 の shutil で写す(既にあれば飛ばす)。PACK.md の `## AGENTS.md 7節に足す行` を、7節最終行 `- 上に無い状況 →` の直前に足す(同じ行があれば飛ばす)
5. `grep -n '未設定>' AGENTS.md work/STATUS.md` が0件と確かめる。残れば埋めてやり直す。diff を見せて `git add -A` → `chore: 初期設定` で commit
6. 最後に1行だけ伝える

## 止まる線
- 答えの無い項目を推測で埋めない
- AGENTS.md の2〜6節・8節と、手順3・4に挙げた以外のファイルを書き換えない。packs/ の元ファイルも書き換えない
- 既定の承認線と上限を減らさない。減らす回答は受け付けず、票で責任者に確かめる。自律度の行を変えない

## 出力
- commit(`.git` が無ければ `chore: はじめる` も)
- AGENTS.md 1節・7節の diff
- 最後の1行: `新しいセッションで「前回の続き」と言えば再開できます。`
失敗時: この手順の該当番号に1行足す
