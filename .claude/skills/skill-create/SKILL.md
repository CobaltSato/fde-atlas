## いつ使うか
同じセッションで同じ手順か注意を2回したとき。人間が「また同じ差し戻し」と言ったとき。「次も使う」「スキルにして」「道具化して」と言われたとき。記録ファイルは数えない。

## 手順
1. 手順と防ぎたい失敗(注意で防げない理由も)を1行で。
2. 軽い順: AGENTS.md 8節に1行 → 既存スキルに1行 → 新スキル。消すか統合できる行も挙げる。足りればそこで終える(以降は新スキルのときだけ)。
3. 新スキルは出力節の形で書く。出力節に確かめ方(入力例と期待する要点を1行)・この手順で見つけられないもの・所要時間(数分以上の処理だけ・実測)を書く。
4. 点検: 40行以内・手順7つ以内・止まる線に操作名・モデル名と曖昧語なし。
5. `.claude/skills/<name>/SKILL.md` に保存し、AGENTS.md 7節の最終行の直前に `- <状況> → /<name>(未検証)` を1行足す。
6. 別セッションの再実行を頼む票を desk/ に置く。

## 止まる線
- 自分での再実行を検証とみなさない。
- `(未検証)` を自分で外さない。票が はい なら /wrap-up が外す。
- 合格基準を自分で決めない。

## 出力
SKILL.md(または足した1行)・AGENTS.md 7節の1行・票。形: frontmatter(先頭の --- で囲む3行: name/description 130バイト以内/updated)、見出し(`## `)4つ: いつ使うか/手順/止まる線/出力。出力節に手順3の3つ。
失敗時: この手順の該当番号に1行足す
