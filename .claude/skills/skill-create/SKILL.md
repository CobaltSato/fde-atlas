## いつ使うか
同じ手順か注意を同じセッションで2回したとき。「次も使う」「スキルにして」と言われたとき。回数の判定は会話だけで行う。

## 手順
1. 手順はこの会話、無ければ work/ の最新 notes-*.md から特定。絞れなければ質問の票。手順と防ぎたい失敗を1行。
2. 軽い順: AGENTS.md 8節に1行 → 既存スキルに1行 → 新スキル。足りれば終える。「スキルにして」なら新スキルまで作る。
3. 新スキルの出力節に確かめ方(入力例と期待する要点を1行)・見つけられないもの・所要時間(数分以上)。
4. 点検: 40行以内・手順7つ以内・止まる線に操作名・モデル名と曖昧語なし。
5. `.claude/skills/<name>/SKILL.md` に保存し、AGENTS.md 7節の最終行の直前に `- <状況> → /<name>(未検証)` を足す。
6. 票「<name> の再実行の確認」を desk/ に置く。Q1「別セッションで実行した結果が期待どおりでしたか?」。リンクは SKILL.md。操作は claude を終了→起動→入力例。

## 止まる線
- 自分での再実行を検証とみなさない。
- `(未検証)` を自分で外さない。票の Q1 が はい のときだけ /wrap-up が外す。
- 合格基準を自分で決めない。

## 出力
SKILL.md・7節の1行・票。形: frontmatter(name/description 130バイト以内/updated の3キー)、H2 4つ(いつ使うか/手順/止まる線/出力)。出力節に手順3の3つ。
失敗時: この手順の該当番号に1行足す
