## いつ使うか
「調べて」「調査して」「確認して」「これって本当?」と頼まれたとき。

## 手順
1. 問い・目的・完了条件・上限を確かめる。上限は AGENTS.md 1節に従う。欠けていれば質問の票1枚にまとめる。
2. `date` で調査日を取る。
3. 作業フォルダ → AGENTS.md 1節の正本 → Web の順に調べる。答えが出たら先へ進まない。
4. 事実ごとに出典・確認日・区分(原典/関連/解釈)を付ける。数字には単位と期間を書く。確かめられない事実は「見つからなかったこと」へ。理由は原典にあるものだけ書く。
5. 長い出典は要点を同じファイルに書く。次回はそれを読む。
6. 保存する。
7. 結論3行と確信度(高/中/低)を報告する。低なら、何が分かれば上がるかを添える。

## 止まる線
- 購入・フォーム送信・ログイン・認証情報の入力をしない。
- 上限に達したら止めて報告する。

## 出力
`work/<業務>/research-YYYYMMDD-<題>.md`
- 1行目: `# 調査: <問い>(調査日 YYYY-MM-DD)`
- H2 は4つ: 結論(3行以内・確信度)/ 根拠(表 事実|出典|確認日|区分)/ 見つからなかったこと / 未解決

失敗時: この手順の該当番号に1行足す
